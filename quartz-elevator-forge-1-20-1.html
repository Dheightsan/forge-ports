Quartz Elevator for Forge 1.20.1

Aton-Kish's quartz elevators, taken from Fabric 1.20.4 back to Forge 1.20.1. Free, credited, and the code is on GitHub.

Download on CurseForge Code on GitHub

Versions

  • From: Fabric 1.20.4
  • To: Forge 1.20.1
  • Licence: MIT
  • Tested: Dedicated server and client

What changed in the port

The settings moved from Auto Config to a Forge config file, with the same five options. Slimes don't fire Forge's jump event, so I kept the original mixins instead of switching to it. On a dedicated server and in the client I tested going up and down, both elevator types, the four recipes and reopening a saved world.

I wrote down what usually breaks going from Fabric to Forge.
